## Reading rule

Distinguish three labels throughout the documents:

- **Research finding:** reported by a cited external source, with its limitations.
- **Product hypothesis:** a mechanism PureFlow proposes but has not proven.
- **Target:** a threshold used to decide whether to continue, never a measured result unless an experiment log says so.
